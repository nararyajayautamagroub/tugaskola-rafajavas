# SMK PHI Landing Page

Landing page sederhana dan responsif untuk pengenalan **SMK PHI (Persada Husada Indonesia)**.

## Fitur
- HTML semantik dan bahasa halaman Indonesia.
- Desain responsif untuk ponsel, tablet, dan desktop.
- Navigasi mobile dengan dukungan atribut aksesibilitas.
- Metadata SEO dasar, Open Graph, dan structured data Schema.org.
- CSS dan JavaScript ringan tanpa dependensi eksternal.
- Menghindari publikasi alamat, nomor kontak, jurusan, dan data lain yang belum terverifikasi.

## Struktur
- `index.html`: halaman utama beserta CSS dan JavaScript.

## Menjalankan secara lokal
Buka `index.html` melalui browser. Tidak membutuhkan proses build atau instalasi paket.

## Deploy dengan GitHub Pages
1. Buka **Settings → Pages** di repository.
2. Pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/(root)`, lalu simpan.
4. Setelah deployment selesai, gunakan URL Pages yang diberikan GitHub sebagai URL resmi situs.

## Catatan SEO
Setelah URL publik ditetapkan, tambahkan URL kanonis dan sitemap yang memakai domain yang benar. Data kontak, alamat, program keahlian, serta tautan resmi sekolah perlu diverifikasi sebelum dipublikasikan. Structured data saat ini hanya memuat nama dan deskripsi umum.
